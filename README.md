# 📚 Library Management System

A simple and responsive **Library Management System** developed using **HTML, CSS, and JavaScript**. The application provides an easy-to-use dashboard for managing library book records with basic CRUD operations.

## 🌐 Live Demo

**Live Website:**
https://rubashrijanci.github.io/library-management-system-/

## 📌 Project Overview

The Library Management System is a web-based application designed to simplify basic library book management.

The system allows users to:

* Add new books
* View available books
* Update book information
* Delete book records
* Search books
* Check book availability
* View total, available, and issued book counts

The project demonstrates the implementation of **CRUD operations, form validation, search functionality, responsive UI design, and browser-based data storage**.

## 🎯 Objectives

* Create a simple and user-friendly library dashboard.
* Manage book records efficiently.
* Implement Create, Read, Update, and Delete operations.
* Provide search functionality for books.

* Practice frontend web development using HTML, CSS, and JavaScript.

## 💾 Data Storage

This project uses **browser LocalStorage** to store book records.

Therefore, the data can remain available when the page is refreshed in the same browser.

> Note: This project does not use a server-side database such as MySQL, SQLite, or PostgreSQL.
